Moods, in pixels

Here is one mood system shared by all 15 coaches. Each mood changes the eyes and adds a small pixel effect, so every character gets all four moods without being redrawn four times. Everything moves in whole pixels.

Idle1-pixel bob, blinks every few seconds Thinkingeyes glance up, "…" dots fill in one by one above the head (while you wait for a reply) Answeringhappy ^ ^ eyes and a quicker 2-pixel hop (just after a reply) Restingeyes closed, colours dimmed, "z" pixels drift up, slow bob (low-recovery days)

Every size the app uses

Pixel art only looks sharp when every sprite pixel covers a whole number of screen pixels. So each size snaps to the nearest crisp scale (on a 3× iPhone, 24 sprite pixels × 2 screen pixels = 16pt, × 3 = 24pt, and so on) and centres in its slot. The full body stays readable even at 18pt, so I'd drop the separate head-only "mini" version and use one sprite everywhere.
