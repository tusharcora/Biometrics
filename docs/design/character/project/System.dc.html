VARIATION SYSTEM

A variant is data, not art: base + two colours + up to five items + a mood. It composes into one 24 × 24 cell grid, the same shape the coach compositor already returns, so CharacterCanvas can draw it unchanged.

LAYER STACK · BACK TO FRONT

0backgroundoptional plate: tint, night, meadow
1back itemsslot back (cape), drawn before the body
2bodybase half mirrored; b auto-split into h / b / s
3antennaa bulb + k stalk; skipped if a head item hides it
4facemood cells: eyes, mouth, cheeks, fx glyph
5front itemshead → face → neck → hand, one per slot
6outline pass1 px in outline colour around the union of 1–5
7framebob shifts all but the shadow up 1; blink, pulse

Letters b h s e w c m match sprites/data.ts, so the art ports with the existing script.

AN ITEM

"hat.crown": { "slot": "head", "hideAntenna": true, "at": [7, 4], "rows": ["g...gg...g", "gg..gg..gg", "gggggggggg", "ggjgbbgjgg", "dddddddddd"], "pal": { "g": "#FACC15", "d": "#CA8A04", "j": "#EF4444", "b": "#60A5FA" } }

Rows are read left to right from the origin; a dot is empty. A pal value of @accent or @accentDark pulls from the variant's colourway. Adding an item is one entry here and zero changes to the body.
