# Social S1 — Navigation, Activity, Social home — Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ship build phase S1 of the Social tab: Social replaces Metrics in the tab bar, Activity absorbs Metrics
(with a pushed Trends screen), and a new Social home shows a static camp banner, stories with a morning check-in,
a week-highlights carousel, today's timeline and a Chats button (opening the existing Buddies screens until S3).

**Architecture:** A new backend module `backend/src/social/` (own router `socialRouter`, routes under `/me/social…`)
builds every view at read time from rows it already has plus four small new tables (check-ins, story seen,
recap shares, step-goal events) and one cache (weekly highlights) — Buddies' "Approach A". All gating reuses the
Buddies helpers (`effectiveSharing`, live `BuddyPair` rows). Mobile adds `src/api/social.ts`, a module store
`src/lib/socialStore.ts` (mirrors `buddiesStore`), a `SocialScreen` tab, a `SocialStory` modal (reuses the recap
story-viewer engine) and a `Highlights` screen.

**Tech Stack:** Express 5 + Prisma (Postgres) + BullMQ backend (TypeScript, Jest + supertest); Expo 57 / React
Native app (NativeWind, React Navigation 7, Jest + React Native Testing Library).

**Spec:** `docs/superpowers/specs/2026-10-07-social-tab-design.md` (§2, §3, §4, §4.1, §4.2, §5, §7, §9, §12 S1).

  - A locked check-in frame comes back as `{ kind: 'checkin', locked: true }` instead of a `checkin_locked` error

  - Activity's 2×2 grid is **Resting HR, Sleep, HRV + a Patterns tile** (spec §3 listed Recovery; the app has no
    recovery-history client yet).
  - A shared recap frame shows the recap's headline line, period and coach only — **never its stats**.
  - Old backend (`GET /me/social` → bare 404): the Social tab shows a card "Social isn't available yet" with an
    "Open Buddies" button (spec §4 said "the Buddies fallback").

## Review Focus

1. **Viewer and buddy in different time zones** (Auckland vs Los Angeles): a story follows the **author's** day —
   an Auckland buddy's check-in made on their Oct 8 morning shows now and disappears at Auckland midnight, wherever
   the viewer is; the timeline follows the **viewer's** day — an event is listed when its moment falls inside the
   viewer's local today. Tests: Task 4 (stories), Task 5 (timeline).
2. **Sharing switched off after a badge or step goal today:** the badge/step frame, timeline item and highlight
   must disappear on the very next read. Tests: Task 4, Task 5, Task 6.
3. **Unpair or block mid-day:** that person's ring, story, timeline items and highlight items vanish, and
   `GET /me/social/stories/:id` answers `not_buddies`. Tests: Task 4, Task 6.
4. **Check-in edited, then local midnight passes:** a second save the same local day updates the row; after
   midnight the next save is a new day's row; your ring's lock lifts the moment you save. Tests: Task 2, Task 4.
5. **Old backend or offline:** `/me/social` 404 or a network error — the Social tab shows the fallback or a retry,
   the tab-bar dot stays hidden, nothing crashes. Tests: Task 10, Task 12.

```prisma
  RESTED

  author    User     @relation("StorySeenAuthor", fields: [authorId], references: [id], onDelete: Cascade)
```

```ts
// Morning check-in (spec 2026-10-07 social §4.1): Rested / Okay / Tired, one per author per LOCAL day, editable
// until local midnight, always shared with buddies (self-reported, no number).

import type { CheckInMood } from '@prisma/client';
import { civilDateToUtcMidnight, localCivilDateOrUtc } from '../biometrics/civilDate';
import { prisma } from '../db/client';
import { BuddyError } from '../buddies/errors';

export const CHECKIN_MOODS: readonly CheckInMood[] = ['RESTED', 'OKAY', 'TIRED'];

export interface CheckInDTO {
  mood: CheckInMood;
  localDate: string;
  updatedAt: string;
}

const isoDate = (d: Date) => d.toISOString().slice(0, 10);
const toDTO = (row: { mood: CheckInMood; localDate: Date; updatedAt: Date }): CheckInDTO => ({
  mood: row.mood,
  localDate: isoDate(row.localDate),
  updatedAt: row.updatedAt.toISOString(),
});

/** The user's zone and civil "today". */
export async function todayFor(userId: string, now: Date): Promise<{ timezone: string; today: string }> {
  const user = await prisma.user.findUniqueOrThrow({ where: { id: userId }, select: { timezone: true } });
  return { timezone: user.timezone, today: localCivilDateOrUtc(now, user.timezone) };
}

export async function getTodayCheckIn(userId: string, now: Date): Promise<CheckInDTO | null> {
  const { today } = await todayFor(userId, now);
  const row = await prisma.checkIn.findUnique({
    where: { authorId_localDate: { authorId: userId, localDate: civilDateToUtcMidnight(today) } },
    select: { mood: true, localDate: true, updatedAt: true },
  });
  return row ? toDTO(row) : null;
}

export async function saveCheckIn(userId: string, mood: unknown, now: Date): Promise<CheckInDTO> {
  if (!(CHECKIN_MOODS as readonly unknown[]).includes(mood)) throw new BuddyError('invalid_checkin');
  const { today } = await todayFor(userId, now);
  const localDate = civilDateToUtcMidnight(today);
  const row = await prisma.checkIn.upsert({
    where: { authorId_localDate: { authorId: userId, localDate } },
    create: { authorId: userId, localDate, mood: mood as CheckInMood, createdAt: now },
    update: { mood: mood as CheckInMood },
    select: { mood: true, localDate: true, updatedAt: true },
  });
  return toDTO(row);
}
```

```ts
// "Passed the step goal today" (spec 2026-10-07 social §5): written by the sync the first time a STEPS rollup for
// the user's LOCAL today reaches STEPS_GOAL. Stores the day only — never a step count. Buddies see it only while
// the author effectively shares steps (gated at read time, not here).

import { civilDateToUtcMidnight } from '../biometrics/civilDate';
import { STEPS_GOAL } from '../coach/tools/metrics';
import { prisma } from '../db/client';
import { todayFor } from './checkins';

export async function recordStepGoal(userId: string, points: ReadonlyArray<{ recordedAt: Date; value: number }>, now: Date): Promise<boolean> {
  const { today } = await todayFor(userId, now);
  const todayPoint = points.find((p) => p.recordedAt.toISOString().slice(0, 10) === today);
  if (!todayPoint || todayPoint.value < STEPS_GOAL) return false;
  const created = await prisma.stepGoalEvent.createMany({
    data: [{ authorId: userId, localDate: civilDateToUtcMidnight(today), at: now }],
    skipDuplicates: true,
  });
  return created.count === 1;
}
```

```ts
// "Share with buddies" on a recap (spec 2026-10-07 social §4.2): an explicit per-recap action by its owner. The

import { civilDateToUtcMidnight } from '../biometrics/civilDate';

import { todayFor } from './checkins';

export async function shareRecap(userId: string, recapId: unknown, now: Date): Promise<{ shared: true }> {
  if (typeof recapId !== 'string' || !UUID_RE.test(recapId)) throw new BuddyError('recap_not_found');

    skipDuplicates: true,
  });
  return { shared: true };
}

  await prisma.recapShare.deleteMany({ where: { sharerId: userId, recapId } });
}
```

```ts
// Stories (spec 2026-10-07 social §4.2). A story is the AUTHOR's local today: their check-in (locked for a viewer
// who hasn't checked in today), badges earned today (only while they share streaks) and recaps they shared today
// (headline, period and coach only). Built at read time with one query per source for the whole circle.

import type { AchievementFamily, CheckInMood } from '@prisma/client';
import { civilDateToUtcMidnight, localCivilDateOrUtc } from '../biometrics/civilDate';
import { prisma } from '../db/client';
import { BuddyError, UUID_RE } from '../buddies/errors';
import type { PersonDTO } from '../buddies/people';
import { buddyIdsOf, membersById, type Member } from './circle';

export type StoryFrameDTO =
  | { kind: 'checkin'; at: string; locked: true }
  | { kind: 'checkin'; at: string; locked: false; mood: CheckInMood }
  | { kind: 'badge'; at: string; family: AchievementFamily; level: number }
  | { kind: 'recap'; at: string; recapId: string; recapKind: 'WEEK' | 'MONTH'; periodStart: string; periodEnd: string; line: string; coachId: string };

export interface StoryDTO { author: PersonDTO; localDate: string; frames: StoryFrameDTO[] }
export interface StoryRingDTO { author: PersonDTO; unseen: boolean; locked: boolean; frameCount: number; latestAt: string }

const LOOKBACK_MS = 48 * 60 * 60 * 1000;
const iso = (d: Date) => d.toISOString();
const isoDate = (d: Date) => d.toISOString().slice(0, 10);

/** Each author's frames for their own local today. `unlocked` = the viewer may see check-in moods. */
async function loadFrames(authors: Member[], now: Date, unlocked: (authorId: string) => boolean): Promise<Map<string, StoryFrameDTO[]>> {
  const ids = authors.map((a) => a.person.id);
  const todayOf = new Map(authors.map((a) => [a.person.id, localCivilDateOrUtc(now, a.timezone)]));
  const since = new Date(now.getTime() - LOOKBACK_MS);
  const streakIds = authors.filter((a) => a.shares.streaks).map((a) => a.person.id);
  const [checkIns, badges, shares] = await Promise.all([
    prisma.checkIn.findMany({
      where: { authorId: { in: ids }, localDate: { in: [...new Set(todayOf.values())].map(civilDateToUtcMidnight) } },
      select: { authorId: true, localDate: true, mood: true, createdAt: true },
    }),
    prisma.achievement.findMany({
      where: { userId: { in: streakIds }, createdAt: { gte: since } },
      select: { userId: true, family: true, level: true, createdAt: true },
    }),
    prisma.recapShare.findMany({
      where: { sharerId: { in: ids }, createdAt: { gte: since } },
      select: { sharerId: true, localDate: true, createdAt: true, recap: { select: { id: true, kind: true, periodStart: true, periodEnd: true, line: true } } },
    }),
  ]);
  const byAuthor = new Map<string, Array<StoryFrameDTO>>(ids.map((id) => [id, []]));
  const coachOf = new Map(authors.map((a) => [a.person.id, a.person.coachId]));
  const tzOf = new Map(authors.map((a) => [a.person.id, a.timezone]));
  for (const c of checkIns) {
    if (isoDate(c.localDate) !== todayOf.get(c.authorId)) continue;
    byAuthor.get(c.authorId)!.push(unlocked(c.authorId)
      ? { kind: 'checkin', at: iso(c.createdAt), locked: false, mood: c.mood }
      : { kind: 'checkin', at: iso(c.createdAt), locked: true });
  }
  for (const b of badges) {
    if (localCivilDateOrUtc(b.createdAt, tzOf.get(b.userId)!) !== todayOf.get(b.userId)) continue;
    byAuthor.get(b.userId)!.push({ kind: 'badge', at: iso(b.createdAt), family: b.family, level: b.level });
  }
  for (const s of shares) {
    if (isoDate(s.localDate) !== todayOf.get(s.sharerId)) continue;
    byAuthor.get(s.sharerId)!.push({
      kind: 'recap', at: iso(s.createdAt), recapId: s.recap.id, recapKind: s.recap.kind,
      periodStart: isoDate(s.recap.periodStart), periodEnd: isoDate(s.recap.periodEnd), line: s.recap.line, coachId: coachOf.get(s.sharerId)!,
    });
  }
  for (const frames of byAuthor.values()) frames.sort((a, b) => a.at.localeCompare(b.at));
  return byAuthor;
}

async function viewerCheckedInToday(viewer: Member, now: Date): Promise<boolean> {
  const today = localCivilDateOrUtc(now, viewer.timezone);
  const row = await prisma.checkIn.findUnique({
    where: { authorId_localDate: { authorId: viewer.person.id, localDate: civilDateToUtcMidnight(today) } },
    select: { authorId: true },
  });
  return row !== null;
}

export async function loadStoryRings(viewerId: string, now: Date): Promise<{ rings: StoryRingDTO[]; checkedInBuddies: number; viewerCheckedIn: boolean }> {
  const buddyIds = await buddyIdsOf(viewerId);
  const members = await membersById([viewerId, ...buddyIds]);
  const viewer = members.get(viewerId)!;
  const viewerCheckedIn = await viewerCheckedInToday(viewer, now);
  const buddies = buddyIds.map((id) => members.get(id)).filter((m): m is Member => m !== undefined);
  const frames = await loadFrames(buddies, now, () => viewerCheckedIn);
  const seen = await prisma.storySeen.findMany({ where: { viewerId, authorId: { in: buddyIds } }, select: { authorId: true, localDate: true } });
  const seenToday = new Set(seen
    .filter((s) => isoDate(s.localDate) === localCivilDateOrUtc(now, members.get(s.authorId)?.timezone ?? 'UTC'))
    .map((s) => s.authorId));
  const rings: StoryRingDTO[] = [];
  let checkedInBuddies = 0;
  for (const b of buddies) {
    const list = frames.get(b.person.id) ?? [];
    if (list.length === 0) continue;
    const hasCheckIn = list.some((f) => f.kind === 'checkin');
    if (hasCheckIn) checkedInBuddies += 1;
    rings.push({ author: b.person, unseen: !seenToday.has(b.person.id), locked: hasCheckIn && !viewerCheckedIn, frameCount: list.length, latestAt: list[list.length - 1]!.at });
  }
  rings.sort((a, b) => Number(b.unseen) - Number(a.unseen) || b.latestAt.localeCompare(a.latestAt));
  return { rings, checkedInBuddies, viewerCheckedIn };
}

async function requireAuthor(viewerId: string, authorId: string): Promise<{ viewer: Member; author: Member }> {
  if (!UUID_RE.test(authorId)) throw new BuddyError('not_buddies');
  if (authorId !== viewerId && !(await buddyIdsOf(viewerId)).includes(authorId)) throw new BuddyError('not_buddies');
  const members = await membersById([viewerId, authorId]);
  const viewer = members.get(viewerId);
  const author = members.get(authorId);
  if (!viewer || !author) throw new BuddyError('not_buddies');
  return { viewer, author };
}

export async function getStory(viewerId: string, authorId: string, now: Date): Promise<StoryDTO> {
  const { viewer, author } = await requireAuthor(viewerId, authorId);
  const unlocked = authorId === viewerId || (await viewerCheckedInToday(viewer, now));
  const frames = await loadFrames([author], now, () => unlocked);
  return { author: author.person, localDate: localCivilDateOrUtc(now, author.timezone), frames: frames.get(authorId) ?? [] };
}

export async function markStorySeen(viewerId: string, authorId: string, now: Date): Promise<void> {
  const { author } = await requireAuthor(viewerId, authorId);
  const localDate = civilDateToUtcMidnight(localCivilDateOrUtc(now, author.timezone));
  await prisma.storySeen.createMany({ data: [{ viewerId, authorId, localDate, seenAt: now }], skipDuplicates: true });
}
```

```ts
// Today timeline (spec 2026-10-07 social §5): your circle's events whose moment falls in the VIEWER's local today,
// oldest first. Closed kinds with typed fields (the app renders the copy) — never free text, never a health number.
// Step goals only while the author shares steps; badges only while they share streaks (both via effectiveSharing).

import type { AchievementFamily, CheckInMood, StickerKind } from '@prisma/client';
import { localCivilDateOrUtc } from '../biometrics/civilDate';
import { prisma } from '../db/client';
import type { PersonDTO } from '../buddies/people';
import { buddyIdsOf, membersById, type Member } from './circle';

type Base = { id: string; at: string; actor: PersonDTO; mine: boolean };
export type TimelineItemDTO =
  | (Base & { kind: 'checkin'; mood: CheckInMood })
  | (Base & { kind: 'step_goal' })
  | (Base & { kind: 'badge'; badge: { family: AchievementFamily; level: number } })
  | (Base & { kind: 'sticker'; sticker: StickerKind; to: PersonDTO })
  | (Base & { kind: 'recap_share'; recapKind: 'WEEK' | 'MONTH' });

const WINDOW_MS = 30 * 60 * 60 * 1000;

export async function buildTimeline(viewerId: string, now: Date, limit = 100): Promise<TimelineItemDTO[]> {
  const buddyIds = await buddyIdsOf(viewerId);
  const ids = [viewerId, ...buddyIds];
  const members = await membersById(ids);
  const viewer = members.get(viewerId)!;
  const today = localCivilDateOrUtc(now, viewer.timezone);
  const since = new Date(now.getTime() - WINDOW_MS);
  const visible = (m: Member | undefined, key: 'steps' | 'streaks') => m !== undefined && (m.person.id === viewerId || m.shares[key]);
  const stepIds = ids.filter((id) => visible(members.get(id), 'steps'));
  const streakIds = ids.filter((id) => visible(members.get(id), 'streaks'));

  const [checkIns, steps, badges, stickers, shares] = await Promise.all([
    prisma.checkIn.findMany({ where: { authorId: { in: ids }, createdAt: { gte: since } }, select: { id: true, authorId: true, mood: true, createdAt: true } }),
    prisma.stepGoalEvent.findMany({ where: { authorId: { in: stepIds }, at: { gte: since } }, select: { authorId: true, localDate: true, at: true } }),
    prisma.achievement.findMany({ where: { userId: { in: streakIds }, createdAt: { gte: since } }, select: { id: true, userId: true, family: true, level: true, createdAt: true } }),
    prisma.sticker.findMany({
      where: { sentAt: { gte: since }, OR: [{ toUserId: viewerId, fromUserId: { in: buddyIds } }, { fromUserId: viewerId, toUserId: { in: buddyIds } }] },
      select: { id: true, fromUserId: true, toUserId: true, kind: true, sentAt: true },
    }),
    prisma.recapShare.findMany({ where: { sharerId: { in: ids }, createdAt: { gte: since } }, select: { id: true, sharerId: true, createdAt: true, recap: { select: { kind: true } } } }),
  ]);

  const items: TimelineItemDTO[] = [];
  const push = (actorId: string, at: Date, rest: Omit<TimelineItemDTO, 'at' | 'actor' | 'mine'>) => {
    const actor = members.get(actorId);
    if (!actor || localCivilDateOrUtc(at, viewer.timezone) !== today) return;
    items.push({ ...rest, at: at.toISOString(), actor: actor.person, mine: actorId === viewerId } as TimelineItemDTO);
  };
  for (const c of checkIns) push(c.authorId, c.createdAt, { id: `checkin:${c.id}`, kind: 'checkin', mood: c.mood });
  for (const s of steps) push(s.authorId, s.at, { id: `step_goal:${s.authorId}:${s.localDate.toISOString().slice(0, 10)}`, kind: 'step_goal' });
  for (const b of badges) push(b.userId, b.createdAt, { id: `badge:${b.id}`, kind: 'badge', badge: { family: b.family, level: b.level } });
  for (const s of stickers) {
    const to = members.get(s.toUserId);
    if (to) push(s.fromUserId, s.sentAt, { id: `sticker:${s.id}`, kind: 'sticker', sticker: s.kind, to: to.person });
  }
  for (const r of shares) push(r.sharerId, r.createdAt, { id: `recap_share:${r.id}`, kind: 'recap_share', recapKind: r.recap.kind });
  items.sort((a, b) => a.at.localeCompare(b.at) || a.id.localeCompare(b.id));
  return items.slice(-limit);
}
```

```ts
// Week highlights (spec 2026-10-07 social §7): last completed Monday–Sunday week of the viewer's circle, built on
// the first read after the week ends and cached (plan ruling). Closed item types, no health numbers — the only
// counts are the circle's own actions (stickers). Gated again at every read: an actor who is no longer a buddy
// drops out, and a badge item needs the actor to still share streaks.

import type { AchievementFamily, CheckInMood, Prisma } from '@prisma/client';
import { civilDateToUtcMidnight } from '../biometrics/civilDate';
import { prisma } from '../db/client';
import type { PersonDTO } from '../buddies/people';
import { lastCompletedPeriodStart } from '../recap/periods';
import { shiftDate } from '../scoring/dates';
import { todayFor } from './checkins';
import { buddyIdsOf, membersById } from './circle';

export type HighlightItem =
  | { type: 'top_story'; reason: 'badge'; actorId: string; family: AchievementFamily; level: number }
  | { type: 'top_story'; reason: 'checked_in_every_day'; actorId: string }
  | { type: 'most_cheered'; actorId: string; count: number }
  | { type: 'comeback'; actorId: string }
  | { type: 'checked_in_every_day'; actorId: string }
  | { type: 'most_stickers_sent'; actorId: string; count: number };

type WithoutActorId<T> = T extends unknown ? Omit<T, 'actorId'> & { actor: PersonDTO; mine: boolean } : never;
export type HighlightItemDTO = WithoutActorId<HighlightItem>;
export interface HighlightsDTO { weekStart: string; weekEnd: string; items: HighlightItemDTO[] }

const MAX_EVERY_DAY = 3;

function topBy(counts: Map<string, number>, min: number): [string, number] | null {
  const best = [...counts.entries()].sort((a, b) => b[1] - a[1] || a[0].localeCompare(b[0]))[0];
  return best && best[1] >= min ? best : null;
}

export async function buildHighlightItems(memberIds: string[], streakIds: ReadonlySet<string>, weekStart: string): Promise<HighlightItem[]> {
  const from = civilDateToUtcMidnight(weekStart);
  const to = civilDateToUtcMidnight(shiftDate(weekStart, 6));
  const end = civilDateToUtcMidnight(shiftDate(weekStart, 7));
  const [checkIns, badges, stickers] = await Promise.all([
    prisma.checkIn.findMany({ where: { authorId: { in: memberIds }, localDate: { gte: from, lte: to } }, orderBy: { localDate: 'asc' }, select: { authorId: true, mood: true } }),
    prisma.achievement.findMany({ where: { userId: { in: [...streakIds] }, earnedOn: { gte: from, lte: to } }, orderBy: [{ level: 'desc' }, { earnedOn: 'asc' }], select: { userId: true, family: true, level: true } }),
    prisma.sticker.findMany({ where: { fromUserId: { in: memberIds }, toUserId: { in: memberIds }, sentAt: { gte: from, lt: end } }, select: { fromUserId: true, toUserId: true } }),
  ]);

  const moods = new Map<string, CheckInMood[]>();
  for (const c of checkIns) moods.set(c.authorId, [...(moods.get(c.authorId) ?? []), c.mood]);
  const everyDay = [...moods.entries()].filter(([, list]) => list.length === 7).map(([id]) => id).sort();
  const comeback = [...moods.entries()].find(([, list]) => list.some((m, i) => m === 'RESTED' && i >= 2 && list[i - 1] === 'TIRED' && list[i - 2] === 'TIRED'));
  const received = new Map<string, number>();
  const sent = new Map<string, number>();
  for (const s of stickers) {
    received.set(s.toUserId, (received.get(s.toUserId) ?? 0) + 1);
    sent.set(s.fromUserId, (sent.get(s.fromUserId) ?? 0) + 1);
  }

  const items: HighlightItem[] = [];
  const badge = badges[0];
  if (badge) items.push({ type: 'top_story', reason: 'badge', actorId: badge.userId, family: badge.family, level: badge.level });
  else if (everyDay[0]) items.push({ type: 'top_story', reason: 'checked_in_every_day', actorId: everyDay[0] });
  const cheered = topBy(received, 2);
  if (cheered) items.push({ type: 'most_cheered', actorId: cheered[0], count: cheered[1] });
  if (comeback) items.push({ type: 'comeback', actorId: comeback[0] });
  for (const id of everyDay.filter((id) => !(items[0]?.type === 'top_story' && items[0].actorId === id)).slice(0, MAX_EVERY_DAY)) {
    items.push({ type: 'checked_in_every_day', actorId: id });
  }
  const sender = topBy(sent, 3);
  if (sender) items.push({ type: 'most_stickers_sent', actorId: sender[0], count: sender[1] });
  return items;
}

export async function getWeeklyHighlights(viewerId: string, now: Date): Promise<HighlightsDTO | null> {
  const { today } = await todayFor(viewerId, now);
  const weekStart = lastCompletedPeriodStart('WEEK', today);
  const memberIds = [viewerId, ...(await buddyIdsOf(viewerId))];
  const members = await membersById(memberIds);
  const key = { viewerId_weekStart: { viewerId, weekStart: civilDateToUtcMidnight(weekStart) } };
  let row = await prisma.weeklyHighlights.findUnique({ where: key, select: { items: true } });
  if (!row) {
    const streakIds = new Set(memberIds.filter((id) => id === viewerId || members.get(id)?.shares.streaks));
    const items = await buildHighlightItems(memberIds, streakIds, weekStart);
    await prisma.weeklyHighlights.createMany({
      data: [{ viewerId, weekStart: civilDateToUtcMidnight(weekStart), items: items as unknown as Prisma.InputJsonValue }],
      skipDuplicates: true,
    });
    row = await prisma.weeklyHighlights.findUniqueOrThrow({ where: key, select: { items: true } });
  }
  const visible: HighlightItemDTO[] = [];

    const { actorId, ...rest } = item;
    visible.push({ ...rest, actor: actor.person, mine: actorId === viewerId } as HighlightItemDTO);
  }
  return visible.length > 0 ? { weekStart, weekEnd: shiftDate(weekStart, 6), items: visible } : null;
}
```

```ts
// The Social home in one call (spec 2026-10-07 social §4). The camp is static in S1: a count of who in your
// circle checked in today. Unread counts feed the Social tab's dot: incoming buddy requests and unseen stickers
// from current buddies (chats join in S3).

import { prisma } from '../db/client';
import { countRequests } from '../buddies/requests';
import type { PersonDTO } from '../buddies/people';
import { getTodayCheckIn, type CheckInDTO } from './checkins';
import { buddyIdsOf, membersById } from './circle';
import { getWeeklyHighlights, type HighlightsDTO } from './highlights';
import { loadStoryRings, type StoryRingDTO } from './stories';
import { buildTimeline, type TimelineItemDTO } from './timeline';

export interface SocialHomeDTO {
  me: { person: PersonDTO; checkIn: CheckInDTO | null };
  camp: { checkedIn: number; members: number };
  stories: StoryRingDTO[];
  highlights: HighlightsDTO | null;
  timeline: TimelineItemDTO[];
  unread: { requests: number; stickers: number };
}

export async function getSocialHome(viewerId: string, now: Date): Promise<SocialHomeDTO> {
  const buddyIds = await buddyIdsOf(viewerId);
  const [members, checkIn, rings, timeline, highlights, requests, stickers] = await Promise.all([
    membersById([viewerId]),
    getTodayCheckIn(viewerId, now),
    loadStoryRings(viewerId, now),
    buildTimeline(viewerId, now),
    getWeeklyHighlights(viewerId, now),
    countRequests(viewerId, now),
    prisma.sticker.count({ where: { toUserId: viewerId, seenAt: null, fromUserId: { in: buddyIds } } }),
  ]);
  return {
    me: { person: members.get(viewerId)!.person, checkIn },
    camp: { checkedIn: rings.checkedInBuddies + (rings.viewerCheckedIn ? 1 : 0), members: buddyIds.length + 1 },
    stories: rings.rings,
    highlights,
    timeline,
    unread: { requests: requests.incoming, stickers },
  };
}
```

```ts
// Social copy (spec 2026-10-07 social §5, §7). Fixed templates over typed fields — no free text, no health numbers.

import type { Person } from '../api/buddies';
import type { CheckInMood, HighlightItem, TimelineItem } from '../api/social';
import { FAMILY_NAMES, numeral } from './badges';
import { STICKER_LABEL } from './buddyCopy';

export const CHECKIN_OPTIONS: ReadonlyArray<{ mood: CheckInMood; label: string; color: string }> = [
  { mood: 'RESTED', label: 'Rested', color: '#86EFAC' },
  { mood: 'OKAY', label: 'Okay', color: '#93C5FD' },
  { mood: 'TIRED', label: 'Tired', color: '#FDBA74' },
];
const MOOD_WORD: Record<CheckInMood, string> = { RESTED: 'rested', OKAY: 'okay', TIRED: 'tired' };

export const personName = (p: Person, mine: boolean) => (mine ? 'You' : p.displayName ?? `@${p.handle}`);
const badgeName = (family: keyof typeof FAMILY_NAMES, level: number) => `${FAMILY_NAMES[family]} ${numeral(level)}`;

export function timelineLine(item: TimelineItem): string {
  const who = personName(item.actor, item.mine);
  switch (item.kind) {
    case 'checkin':
      return item.mine ? `You checked in: ${MOOD_WORD[item.mood]}` : `${who} woke up ${MOOD_WORD[item.mood]}`;
    case 'step_goal':
      return item.mine ? 'You passed your step goal' : `${who} passed their step goal`;
    case 'badge':
      return `${who} reached ${badgeName(item.badge.family, item.badge.level)}`;
    case 'sticker':
      return item.mine ? `You sent ${personName(item.to, false)} a ${STICKER_LABEL[item.sticker]}` : `${who} sent you a ${STICKER_LABEL[item.sticker]}`;
    case 'recap_share':
      return `${who} shared ${item.mine ? 'your' : 'their'} ${item.recapKind === 'WEEK' ? 'weekly' : 'monthly'} recap`;
  }
}

export function timelineAction(item: TimelineItem): 'cheer' | 'rest_up' | null {
  if (item.mine || item.kind === 'sticker') return null;
  if (item.kind === 'checkin' && item.mood === 'TIRED') return 'rest_up';
  return 'cheer';
}

export function highlightKicker(item: HighlightItem): string {
  switch (item.type) {
    case 'top_story': return 'Top story';
    case 'most_cheered': return 'Most cheered';
    case 'comeback': return 'Comeback';
    case 'checked_in_every_day': return 'Every day';
    case 'most_stickers_sent': return 'Most generous';
  }
}

export function highlightLine(item: HighlightItem): string {
  const who = personName(item.actor, item.mine);
  switch (item.type) {
    case 'top_story':
      return item.reason === 'badge' ? `${who} reached ${badgeName(item.family, item.level)}` : `${who} checked in every day`;
    case 'most_cheered': return `${who} got ${item.count} stickers`;
    case 'comeback': return `${who} bounced back to rested`;
    case 'checked_in_every_day': return `${who} checked in every day`;
    case 'most_stickers_sent': return `${who} sent ${item.count} stickers`;
  }
}

/** "8:05" style local time for a timeline row. */
export function clockTime(iso: string): string {
  const d = new Date(iso);
  return `${d.getHours()}:${String(d.getMinutes()).padStart(2, '0')}`;
}
```

```ts
      latest: summary ? config.format(summary.latest) : null,

  });
```

```ts
// The Social home, shared by the Social tab and the tab bar's unread dot. Mirrors buddiesStore: one load at a
// time (a refresh during a load reloads once after it), a reset bumps the epoch so a late load can't land, and a
// failed refresh keeps the last good home.

import { useSyncExternalStore } from 'react';
import { fetchSocialHome, type SocialHome } from '../api/social';

export type SocialState = { status: 'idle' } | { status: 'ready'; home: SocialHome } | { status: 'unavailable' } | { status: 'error' };

let state: SocialState = { status: 'idle' };
let epoch = 0;
let inFlight: Promise<void> | null = null;
let dirty = false;
const listeners = new Set<() => void>();

function publish(next: SocialState) {
  state = next;
  for (const l of listeners) l();
}

export const getSocialState = () => state;

export function refreshSocial(): Promise<void> {
  if (inFlight) {
    dirty = true;
    return inFlight;
  }
  const mine = epoch;
  inFlight = (async () => {
    do {
      dirty = false;
      try {
        const home = await fetchSocialHome();
        if (mine !== epoch) return;
        publish(home ? { status: 'ready', home } : { status: 'unavailable' });
      } catch {
        if (mine !== epoch) return;
        if (state.status !== 'ready') publish({ status: 'error' });
      }
    } while (dirty && mine === epoch);
  })().finally(() => { inFlight = null; });
  return inFlight;
}

export function resetSocial() {
  epoch += 1;
  dirty = false;
  inFlight = null;
  publish({ status: 'idle' });
}

const subscribe = (l: () => void) => { listeners.add(l); return () => { listeners.delete(l); }; };
export const useSocial = () => useSyncExternalStore(subscribe, getSocialState, getSocialState);
export function useSocialUnread(): boolean {
  const s = useSocial();
  return s.status === 'ready' && s.home.unread.requests + s.home.unread.stickers > 0;
}
```

```tsx
import React, { useRef, useState } from 'react';
import { View } from 'react-native';
import { saveCheckIn, type CheckInMood } from '../../api/social';
import { buddyErrorCode } from '../../api/buddies';

export function CheckInSheet({ visible, current, onClose }: { visible: boolean; current: CheckInMood | null; onClose: () => void }) {
  const saving = useRef(false);
  const [busy, setBusy] = useState(false);
  const [message, setMessage] = useState<string | null>(null);

  async function choose(mood: CheckInMood) {
    if (saving.current) return;
    saving.current = true;
    setBusy(true);
    setMessage(null);
    try {
      await saveCheckIn(mood);
      void refreshSocial();
      onClose();
    } catch (e) {
      setMessage(buddyErrorMessage(buddyErrorCode(e)));
    } finally {
      saving.current = false;
      setBusy(false);
    }
  }

  return (
    <Sheet visible={visible} onClose={onClose} testID="checkin-sheet">
      <View className="gap-4">
        <Text className="font-display text-display-sm">How did you wake up?</Text>

              {o.label}

          ))}
        </View>
```

```tsx
// Today timeline (spec 2026-10-07 social §5): time, dot, fixed line, one-tap sticker (Cheer / Rest up).

import React, { useRef, useState } from 'react';
import { View } from 'react-native';
import { buddyErrorCode, sendSticker } from '../../api/buddies';
import type { TimelineItem } from '../../api/social';
import { buddyErrorMessage } from '../../lib/buddyCopy';
import { clockTime, timelineAction, timelineLine } from '../../lib/socialCopy';
import { refreshSocial } from '../../lib/socialStore';
import { PressableScale } from '../ui/pressable-scale';
import { Text } from '../ui/text';

const DOT: Record<TimelineItem['kind'], string> = { checkin: '#93C5FD', step_goal: '#FB923C', badge: '#FCD34D', sticker: '#F9A8D4', recap_share: '#A5B4FC' };
const LABEL = { cheer: 'Cheer', rest_up: 'Rest up' } as const;
const KIND = { cheer: 'CHEER', rest_up: 'REST_UP' } as const;

export function TimelineList({ items }: { items: TimelineItem[] }) {
  const sending = useRef(false);
  const [busy, setBusy] = useState(false);
  const [message, setMessage] = useState<string | null>(null);

  async function act(item: TimelineItem, action: 'cheer' | 'rest_up') {
    if (sending.current) return;
    sending.current = true;
    setBusy(true);
    setMessage(null);
    try {
      await sendSticker(item.actor.id, KIND[action]);
      void refreshSocial();
    } catch (e) {
      setMessage(buddyErrorMessage(buddyErrorCode(e)));
    } finally {
      sending.current = false;
      setBusy(false);
    }
  }

  if (items.length === 0) {
    return <Text testID="timeline-empty" className="text-sm text-muted-foreground">Nothing yet today. Check in to get things going.</Text>;
  }
  return (
    <View testID="timeline" className="gap-3">
      {items.map((item) => {
        const action = timelineAction(item);
        return (
          <View key={item.id} testID={`timeline-${item.id}`} className="flex-row items-center gap-3">
            <Text className="w-11 text-right text-xs text-muted-foreground">{clockTime(item.at)}</Text>
            <View style={{ width: 10, height: 10, borderRadius: 5, backgroundColor: DOT[item.kind] }} />
            <Text className="flex-1 text-sm">{timelineLine(item)}</Text>
            {action ? (
              <PressableScale testID={`timeline-${item.id}-action`} accessibilityRole="button" disabled={busy} onPress={() => void act(item, action)}
                className="h-8 justify-center rounded-full border border-border px-3">
                <Text className="text-xs">{LABEL[action]}</Text>
              </PressableScale>
            ) : null}
          </View>
        );
      })}
      {message ? <Text testID="timeline-message" className="text-sm text-destructive">{message}</Text> : null}
    </View>
  );
}
```

```tsx
// chats arrive in S3.

import { Pressable, View } from 'react-native';

import { useNavigation, useRoute } from '@react-navigation/native';

export function SocialStoryScreen() {
  const navigation = useNavigation();
  const { authorId } = (useRoute().params ?? {}) as { authorId: string };
  const [story, setStory] = useState<Story | null>(null);
  const [gone, setGone] = useState(false);

  useEffect(() => {
    let live = true;
    fetchStory(authorId).then((s) => { if (live) setStory(s); }).catch(() => { if (live) setGone(true); });
    return () => { live = false; };
  }, [authorId]);

  if (gone) {
    return (
      <SafeAreaView testID="social-story-gone" className="flex-1 items-center justify-center gap-4 bg-black px-8">

        <Text testID="social-story-close" accessibilityRole="button" onPress={() => navigation.goBack()} className="font-semibold text-white">Close</Text>
      </SafeAreaView>
    );

  if (!story || story.frames.length === 0) return <View testID="social-story-loading" className="flex-1 bg-black" />;
  return <Viewer story={story} onClose={() => navigation.goBack()} />;
}

function Viewer({ story, onClose }: { story: Story; onClose: () => void }) {
  const social = useSocial();
  const mine = social.status === 'ready' && social.home.me.person.id === story.author.id;
  const [checkingIn, setCheckingIn] = useState(false);
  const [message, setMessage] = useState<string | null>(null);
  const sending = useRef(false);
  const seen = useRef(false);
  const viewer = useStoryViewer({ count: story.frames.length, autoAdvance: true, onClose });

  useEffect(() => {
    if (viewer.ended && !seen.current) {
      seen.current = true;
      void markStorySeen(story.author.id).finally(() => { void refreshSocial(); });
      onClose();
    }
  }, [viewer.ended, story.author.id, onClose]);

  async function reply(kind: (typeof STICKERS)[number]['kind']) {
    if (sending.current) return;
    sending.current = true;
    setMessage(null);
    try {
      await sendSticker(story.author.id, kind);
      setMessage('Sent');
    } catch (e) {
      setMessage(buddyErrorMessage(buddyErrorCode(e)));
    } finally {
      sending.current = false;
    }
  }

  const frame = story.frames[viewer.index]!;
  return (
    <SafeAreaView testID="social-story" className="flex-1 bg-[#0F1230]">
      <StoryProgress count={story.frames.length} index={viewer.index} progress={viewer.progress} />
      <View className="flex-row items-center justify-between px-4 py-2">
        <Text className="font-semibold text-white">{story.author.displayName ?? `@${story.author.handle}`}</Text>
        <Text testID="social-story-close" accessibilityRole="button" onPress={viewer.close} className="text-white">Close</Text>
      </View>
      <View testID={`story-frame-${viewer.index}`} className="flex-1">
        <SocialStoryFrame frame={frame} author={story.author} mine={mine} onUnlock={() => { viewer.pause('sheet'); setCheckingIn(true); }} />
        <Pressable testID="social-story-prev" accessibilityLabel="Previous" onPress={viewer.prev} style={{ position: 'absolute', left: 0, top: 0, bottom: 0, width: '30%' }} />
        <Pressable testID="social-story-next" accessibilityLabel="Next" onPress={viewer.next} style={{ position: 'absolute', right: 0, top: 0, bottom: 0, width: '70%' }} />
      </View>
      {mine ? null : (
        <View className="gap-2 px-4 pb-4">
          <View className="flex-row gap-2">
            {STICKERS.map((s) => (
              <Text key={s.kind} testID={`story-reply-${s.kind}`} accessibilityRole="button" onPress={() => void reply(s.kind)}
                className="flex-1 rounded-full border border-white/30 py-2 text-center text-sm text-white">{s.label}</Text>
            ))}
          </View>
          {message ? <Text testID="story-message" className="text-center text-sm text-white/80">{message}</Text> : null}
        </View>
      )}
      <CheckInSheet visible={checkingIn} current={null} onClose={() => { setCheckingIn(false); viewer.resume('sheet'); }} />
    </SafeAreaView>
  );
}
```

```ts
class SeedError extends Error {
  constructor(name: string) { super(name); this.name = name; }
}

export function parseArgs(argv: string[]): { email: string; buddyEmail: string } {
  const at = (flag: string) => { const i = argv.indexOf(flag); return i >= 0 ? argv[i + 1] : undefined; };
  const email = at('--email');
  const buddyEmail = at('--buddy-email');
  if (!email || !buddyEmail) throw new Error('Usage: seedSocial --email <demo> --buddy-email <buddy> (env needs DATABASE_URL)');
  return { email, buddyEmail };
}

export async function seedSocial(opts: { email: string; buddyEmail: string; now?: Date; env?: NodeJS.ProcessEnv }) {
  assertDevDatabase(opts.env ?? process.env);
  const now = opts.now ?? new Date();
  const [me, buddy] = await Promise.all([
    prisma.user.findUnique({ where: { email: opts.email }, select: { id: true } }),
    prisma.user.findUnique({ where: { email: opts.buddyEmail }, select: { id: true } }),
  ]);
  if (!me || !buddy) throw new SeedError('SeedUnknownUser');
  if (!(await prisma.buddyPair.findUnique({ where: { userAId_userBId: orderedPair(me.id, buddy.id) } }))) throw new SeedError('SeedNotBuddies');
  await saveCheckIn(buddy.id, 'TIRED', now);
  const { today } = await todayFor(buddy.id, now);
  await recordStepGoal(buddy.id, [{ recordedAt: civilDateToUtcMidnight(today), value: STEPS_GOAL + 1500 }], now);
  const recap = await prisma.recap.findFirst({ where: { userId: buddy.id, status: 'BUILT' }, orderBy: { periodStart: 'desc' }, select: { id: true } });
  if (recap) await shareRecap(buddy.id, recap.id, now);
  return { buddyCheckedIn: true, stepGoal: true, recapShared: recap !== null };
}

export async function main(argv: string[]) {
  try {
    const result = await seedSocial(parseArgs(argv));
    console.info(JSON.stringify({ event: 'social.seeded', ...result }));
  } catch (err) {
    console.error(JSON.stringify({ event: 'social.seed_failed', error: err instanceof Error ? err.name : 'unknown' }));
    process.exitCode = 1;
  } finally {
    await prisma.$disconnect().catch(() => undefined);
    await syncQueue.close().catch(() => undefined);
    await connection.quit().catch(() => undefined);
  }
}
```
