# Home F Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Home opens on a pixel scene: a cottage, a mailbox and the sky, with your KIP and up to two buddies standing
on the ground. The sky follows today's Recovery weather, a short night or the night itself. Tags on the scene open
Sleep, Tomorrow, Recovery and Recaps. Under it sit a "Today" row, three compact tiles and "Ask Coach about today".
The old hero, tiles, Tomorrow card and buddies row go.

**Architecture:**
- **Backend:** one read, `GET /me/buddies/scene`. It orders all of your buddies by their latest check-in (no
  timestamps leave the server), drops muted ones, and returns two rows, the buddy count and the incoming requests.
  The row builder is shared with the buddy list.
- **Mobile:** a pure module, `lib/home/scene.ts`, is the board engine (`FWeather.dc.html`) ported as data and
  functions: the state rule, the rect layers, the layout maths. `HomeScene` draws it with `react-native-svg` (one
  `Path` per colour per layer). `HomeHeader` sits over the sky. `TodayTiles` holds the Today row, the three tiles
  and Ask Coach. `DashboardScreen` owns every read and the clock.

**Tech Stack:**
- Backend: Express, Prisma/Postgres, Jest with supertest.
- Mobile: Expo/React Native, NativeWind, react-native-svg, Jest with React Native Testing Library.

Spec: `docs/superpowers/specs/2026-10-13-home-f-design.md` (including its §10 review log). Boards:
`docs/design/home/project/F.dc.html` and `FWeather.dc.html`.

## Spec corrections

The spec is binding except for these points, where the code or the boards show it can't be built as written. Each
is applied in the task named.

1. **Buddies are drawn with `Kip`, not `PersonKip`** (Task 4). `PersonKip` crops the grid to the painted cells and
   centres the crop in its box, so the feet would not sit on the ground line and the scale would change with the
   pose. The scene uses `Kip` at scale 3 (the board's sprite: left `cx − 8s`, top `246 − 15s`) with the same
   `PERSON_POSE[personStateOf(mood, night)]` and `kipColourOf(kipColour)` that `PersonKip` uses, so the pose and
   colour still match every other screen.
2. **Rain sits under the tags** (Task 4). The spec lists the tags (layer 6) under the rain (layer 7). On the board
   the rain draws over the KIPs but under the tags, and tags under rain streaks would be hard to read. The rain
   layer also takes `pointerEvents="none"`.
3. **The RECOVERY key's band colour comes from the dark palette** (`COLORS.dark`; Task 4). The scene is a picture
   that keeps its colours in both themes (§7), so it can't follow the light palette. The board's fixed green is
   replaced by the band colour, as the spec says.
4. **"ALL n →" is right-aligned to board x 382** (332 + its 50-point width; Task 4). Left-aligned at 332,
   "3 REQUESTS →" runs off the screen.
5. **Name tags are 72 points wide, not the board's 48** (Task 4). An 8-character name in `text-label` (11 points)
   needs about 70.
6. **Hot tags are clamped onto the screen** (Task 2's `clampTagLeft`, used in Task 4). On a 360-point phone the
   grid is centred at −15, so SLEEP would start at −7 and RECAPS would end past the right edge. A tag that would
   leave the screen is moved inside it, 4 points from the edge. A tag that fits is not moved.
7. **`HomeTiles.test.tsx` is trimmed, not deleted** (Task 8). It also tests `MetricTile`, which stays. Only the
   `RecoveryHero`, `SleepTile` and `CoachTile` blocks and their fixtures go.
8. **The `settings-button` conventions entry moves, it isn't deleted** (Tasks 5 and 7). The raw Profile `Pressable`
   moves from `DashboardScreen.tsx` to `HomeHeader.tsx`. Ask Coach is a `Button` that keeps the
   `coach-entry-button` test ID, so `DashboardCoachEntry.test.tsx` keeps passing unchanged.
9. **`useRecapShelf` is called once, in `DashboardScreen`, and handed to `RecapShelf` as a `shelf` prop** (Task 3).
   A hook called in both the shelf and the screen would be two fetches; the spec asks for one.
10. **"Today's sleep score" uses the same rule as Recovery** (Task 2's `todayScore`): the newest `SLEEP` score, only
    if it is dated today. The spec defines this only for Recovery.
11. **What a wide phone draws at the sides** (Task 2's `sceneBackdrop`). The four sky bands and the four ground
    bands run full width, flat, plus the bottom row's dark line. The dither, the hills, the flowers and the fade's
    checker stay on the grid. The extra sky above the grid gets stars at the board's density (34 per 62 rows) at
    night.
12. **The hint's lilac and amber follow the page's theme** (Task 6). The Today row is on the page, not the scene
    (§7). Amber is the palette's `scoreFair`. Lilac is `#C4B5FD` on dark and `#6D28D9` on light, because the
    board's lilac is unreadable on the light page.
13. **`SyncStatusLine` gets a `light` prop** (Task 5). It hard-codes `text-muted-foreground` and
    `text-destructive`. The spec wants all header text light on every sky.
14. **The Profile button shows your KIP in the fallback states too** (Task 7). The fallback header uses the same
    `ProfileButton` on the page background, so the email-initial avatar goes.
15. **The day rolls with the clock** (Task 7). `today` comes from the `now` state, not from render time. The sleep
    read is keyed on `today`, so after midnight a refocus reads the new night, and yesterday's Recovery score
    stops counting as today's.

```ts
export async function listBuddies(viewerId: string, cursorRaw: unknown, now: Date, pageSize = BUDDY_PAGE_SIZE): Promise<BuddyPageDTO> {
  const cursor = parseCursor(cursorRaw);
  const pairs = await prisma.buddyPair.findMany({
    where: { AND: [{ OR: [{ userAId: viewerId }, { userBId: viewerId }] }, ...(cursor ? [keysetBefore('lastActivityAt', cursor)] : [])] },
    orderBy: [{ lastActivityAt: 'desc' }, { id: 'desc' }],
    take: pageSize + 1,
  });
  const page = pairs.slice(0, pageSize);
  const ids = page.map((p) => (p.userAId === viewerId ? p.userBId : p.userAId));
  const counts = await countRequests(viewerId, now);
  if (ids.length === 0) return { buddies: [], nextCursor: null, incomingRequests: counts.incoming, outgoingRequests: counts.outgoing };

  const buddies = await buddyRows(viewerId, ids, now);
  const last = page[page.length - 1]!;
  return {
    buddies,
    nextCursor: pairs.length > pageSize ? encodeCursor({ at: last.lastActivityAt, id: last.id }) : null,
    incomingRequests: counts.incoming,
    outgoingRequests: counts.outgoing,
  };
}

/** The rows for these buddies, in the order given. A user who no longer exists is skipped. */
export async function buddyRows(viewerId: string, ids: string[], now: Date): Promise<BuddyRowDTO[]> {
  if (ids.length === 0) return [];
  const users = await prisma.user.findMany({ where: { id: { in: ids } }, select: { ...PERSON_SELECT, ...SHARING_SELECT, timezone: true } });
  const sharesSteps = new Set(users.filter((u) => effectiveSharing(u).steps).map((u) => u.id));
  // Any zone's local today is UTC today ± 1, and its yesterday is within UTC today - 2.
  const utcToday = key(now);
  const window = { gte: civilDateToUtcMidnight(shiftDate(utcToday, -2)), lte: civilDateToUtcMidnight(shiftDate(utcToday, 1)) };
  const [scores, steps, unseen] = await Promise.all([
    prisma.dailyScore.findMany({ where: { userId: { in: ids }, type: 'RECOVERY', score: { not: null }, date: window }, select: { userId: true, date: true, score: true } }),
    sharesSteps.size > 0
      ? prisma.biometricRecord.findMany({ where: { userId: { in: [...sharesSteps] }, metricType: 'STEPS', recordedAt: window }, select: { userId: true, recordedAt: true, value: true } })
      : Promise.resolve([] as Array<{ userId: string; recordedAt: Date; value: number }>),
    prisma.sticker.groupBy({ by: ['fromUserId'], where: { toUserId: viewerId, fromUserId: { in: ids }, seenAt: null } }),
  ]);
  const unseenFrom = new Set(unseen.map((u) => u.fromUserId));

  const usersById = new Map(users.map((u) => [u.id, u] as const));
  return ids.flatMap((id): BuddyRowDTO[] => {
    const user = usersById.get(id);
    if (!user) return [];
    const today = localCivilDateOrUtc(now, user.timezone);
    const byDate = new Map(scores.filter((s) => s.userId === id).map((s) => [key(s.date), s.score!] as const));
    const mood = todayMood(byDate, today);
    const yesterday = shiftDate(today, -1);
    const moved = sharesSteps.has(id) && steps.some((s) => s.userId === id && key(s.recordedAt) === yesterday && s.value >= STEPS_GOAL);
    return [{ ...toPerson(user), mood, moodLine: moodLine(mood, { movedALot: moved }), unseenSticker: unseenFrom.has(id) }];
  });
}
```

```ts
// The Home scene's buddies (spec 2026-10-13 Home F §4): at most two, by their latest check-in, newest first
// (createdAt, so editing a check-in moves no one), then those who never checked in, in the list's order. It
// looks across every pair, not a list page. Muted buddies are left out of the rows but counted in the total.
// No check-in time or date leaves here: the order is the only signal.

import { prisma } from '../db/client';
import { buddyRows, type BuddyRowDTO } from './list';
import { countRequests } from './requests';

export const SCENE_BUDDIES = 2;

export interface BuddySceneDTO {
  buddies: BuddyRowDTO[];
  total: number;
  incomingRequests: number;
}

export async function buddyScene(viewerId: string, now: Date): Promise<BuddySceneDTO> {
  const [pairs, mutes, counts] = await Promise.all([
    prisma.buddyPair.findMany({
      where: { OR: [{ userAId: viewerId }, { userBId: viewerId }] },
      orderBy: [{ lastActivityAt: 'desc' }, { id: 'desc' }],
      select: { userAId: true, userBId: true },
    }),
    prisma.buddyMute.findMany({ where: { muterId: viewerId }, select: { mutedId: true } }),
    countRequests(viewerId, now),
  ]);
  const ids = pairs.map((p) => (p.userAId === viewerId ? p.userBId : p.userAId));
  const muted = new Set(mutes.map((m) => m.mutedId));
  const shown = ids.filter((id) => !muted.has(id));
  const latest = shown.length === 0
    ? []
    : await prisma.checkIn.groupBy({ by: ['authorId'], where: { authorId: { in: shown } }, _max: { createdAt: true } });
  const checkedAt = new Map(latest.map((l) => [l.authorId, l._max.createdAt?.getTime() ?? null] as const));
  // sort is stable, so the never-checked-in keep the list's order.
  const ordered = [...shown].sort((a, b) => {
    const x = checkedAt.get(a) ?? null;
    const y = checkedAt.get(b) ?? null;
    if (x === null || y === null) return x === null ? (y === null ? 0 : 1) : -1;
    return y - x;
  });
  return {
    buddies: await buddyRows(viewerId, ordered.slice(0, SCENE_BUDDIES), now),
    total: ids.length,
    incomingRequests: counts.incoming,
  };
}
```

```ts
// Layer 1: four sky bands, each dithered into the one above; stars at night.
export function laySky(s: SceneLook): PxRect[] {
  const r: PxRect[] = [];
  const bh = Math.floor(GY / 4);
  for (let i = 0; i < 4; i++) {
    const y0 = i * bh;
    r.push([0, y0, W, i === 3 ? GY - y0 : bh, s.sky[i]!]);
    if (i > 0) for (let x = i % 2; x < W; x += 2) r.push([x, y0, 1, 1, s.sky[i - 1]!]);
  }
  for (let i = 0; i < (s.stars ?? 0); i++) r.push([(i * 37 + 11) % W, (i * 23 + 5) % (GY - 20), 1, 1, STAR_COLS[i % 3]!]);
  return r;
}

// Layer 2: the sun or moon, clouds, haze, birds and the butterfly.
export function layWeather(s: SceneLook): PxRect[] {
  return s.art.flatMap(([name, ox, oy]) => ART[name].map(([x, y, w, h, c]): PxRect => [ox + x, oy + y, w, h, c]));
}

function mound(r: PxRect[], cx: number, base: number, w: number, h: number, col: string) {
  for (let k = 0; k < h; k++) {
    const ww = Math.max(4, Math.round(w * (1 - (k / h) * (k / h))));
    r.push([cx - Math.floor(ww / 2), base - k - 1, ww, 1, col]);
  }
}

export function flowerSpots(s: SceneLook): readonly (readonly [number, number])[] {

  if (s.flowers === 'few' || s.flowers === 'closed') return FLOWER_SPOTS.slice(0, 5);
  return [];
}

  flowerSpots(s).forEach(([x0, y0], i) => {
    if (s.flowers === 'closed') {

      return;

/** The night dated today (nights are dated by the morning you woke): its main sleep under 6 hours, not a nap. */

  if (!night || night.mainIsNap === true) return false;

/** The next 05:00 or 21:00 after `now`, local time: when the state can next change on its own. */
```

```ts
import { fetchRecaps, type RecapSummary } from '../../api/recaps';
import { todayCivil } from '../heatmap';
import { shelfItems, type ShelfItem } from '../recapShelf';
import { useWatchedRecaps } from '../unwatchedRecap';

/** How many recaps the shelf shows (newest first); "See all" has the rest. */
export const SHELF_LIMIT = 30;

export interface RecapShelfState {
  /** null until the first load lands. */
  recaps: RecapSummary[] | null;
  items: ShelfItem[];
  /** The RECAPS tag's number. */
  unwatchedCount: number;
}

interface FocusSource {
  addListener?: (event: 'focus', callback: () => void) => () => void;
}

// The recap shelf's one fetch (spec 2026-10-13 Home F §4). Home calls this once and hands it to the shelf and the
// RECAPS tag. Loads on mount, on focus and on return to the foreground; only the latest load, while mounted,
// lands, and a failed reload keeps what is shown.
export function useRecapShelf(navigation: FocusSource): RecapShelfState {
  const watched = useWatchedRecaps();
  const [recaps, setRecaps] = useState<RecapSummary[] | null>(null);
  const navRef = useRef(navigation);
  navRef.current = navigation;
  const latest = useRef(0);

  const load = useCallback(async () => {
    const run = ++latest.current;
    try {
      const next = await fetchRecaps({ limit: SHELF_LIMIT });
      if (run === latest.current) setRecaps(next);
    } catch {
      // Nothing new to show.
    }
  }, []);

  useEffect(() => {
    void load();
    const off = navRef.current.addListener?.('focus', () => void load());
    const appState = AppState.addEventListener('change', (state) => {
      if (state === 'active') void load();
    });
    return () => {
      latest.current++;
      off?.();
      appState.remove();
    };
  }, [load]);

  const items = useMemo(() => shelfItems(recaps ?? [], todayCivil(), watched), [recaps, watched]);
  return { recaps, items, unwatchedCount: items.filter((i) => i.unwatched).length };
}
```

```ts
import { BAND_WORD, VERDICT, type WeatherKey } from './recoveryCopy';
import type { ScoreBand } from './scoreInsights';

// Every Home F string (spec 2026-10-13 Home F §4–§5).

const NONE = '—';
const NO_READING = 'no reading yet';
const NAME_MAX = 8;

/** A buddy's name on the scene: upper case; over 8 characters, cut to 7 plus "…". By code point, so emoji stay whole. */
export function sceneName(displayName: string): string {
  const chars = Array.from(displayName.toUpperCase());
  return chars.length > NAME_MAX ? `${chars.slice(0, NAME_MAX - 1).join('')}…` : chars.join('');
}

export const HOME_COPY = {
  none: NONE,
  header: {
    date: (now: Date) => now.toLocaleDateString('en-US', { weekday: 'short', month: 'short', day: 'numeric' }),
    profile: 'Profile and settings',
    profileWithRing: (hint: string) => `Profile. ${hint}`,
  },
  tags: {
    sleep: 'SLEEP',
    tomorrow: 'TMRW',
    recovery: 'RECOVERY',
    recaps: 'RECAPS',
    range: (low: number, high: number) => `${low}–${high}`,
    sleepLabel: (score: number | null, duration: string | null) =>
      score === null ? `Bed: sleep, ${NO_READING}. Open Sleep` : `Bed: sleep ${score}${duration ? `, ${duration}` : ''}. Open Sleep`,
    tomorrowLabel: (range: { low: number; high: number } | null) =>
      range ? `Calendar: tomorrow likely ${range.low} to ${range.high}. Open Tomorrow` : `Calendar: tomorrow, ${NO_READING}. Open Tomorrow`,
    recoveryLabel: (r: { score: number; weather: WeatherKey; band: ScoreBand } | null) =>
      r ? `Sky: recovery ${r.score}, ${VERDICT[r.weather].toLowerCase()}, ${BAND_WORD[r.band]}. Open Recovery` : `Sky: recovery, ${NO_READING}. Open Recovery`,
    recapsLabel: (n: number) => (n > 0 ? `Mailbox: recaps, ${n} new. Open Recaps` : 'Mailbox: recaps, no new recaps. Open Recaps'),
  },
  buddies: {
    label: (fullName: string, moodLine: string) => `${fullName}, ${moodLine}. Open their week`,
    all: (n: number) => `ALL ${n} →`,
    requests: (n: number) => (n === 1 ? '1 REQUEST →' : `${n} REQUESTS →`),
    allLabel: (n: number) => `All ${n} buddies. Open Social`,
    requestsLabel: (n: number) => (n === 1 ? '1 buddy request. Open Social' : `${n} buddy requests. Open Social`),
  },
  today: {
    label: 'Today',
    night: (bedtime: string | null) => (bedtime ? `Wind down · bed by ${bedtime}` : 'Wind down'),
    short: 'Short night overrides KIP’s mood',
    other: 'Tap the scene or a tile',
  },
  tiles: {
    recovery: 'Recovery',
    sleep: 'Sleep',
    tomorrow: 'Tomorrow',
    short: (duration: string) => `${duration} · short`,
    bedBy: (bedtime: string) => `Bed by ${bedtime}`,
    withSleep: (hours: number) => `With ${hours}h sleep`,
  },
  askCoach: (needsConsent: boolean) => (needsConsent ? 'Ask Coach · see what’s shared first' : 'Ask Coach about today'),
} as const;
```

```tsx
import React, { useMemo, useState } from 'react';
import { Pressable, View } from 'react-native';
import Svg, { Path } from 'react-native-svg';
import type { BuddyScene } from '../../api/buddies';
import {
  at, clampTagLeft, kipBox, layGround, layObjects, layRain, laySky, layWeather, pxPaths, sceneBackdrop, sceneOffsetX,
  SCENE_H, SCENE_SPOTS, SCENE_W, STATES, U, type SceneState,
} from '../../lib/home/scene';
import { HOME_COPY, sceneName } from '../../lib/homeCopy';
import type { KipColour } from '../../lib/kip/kipArt';
import { kipColourOf } from '../../lib/kip/kipColour';
import type { WeatherKey } from '../../lib/recoveryCopy';
import type { ScoreBand } from '../../lib/scoreInsights';
import { COLORS } from '../../theme';
import { Kip } from '../kip/Kip';
import { PERSON_POSE, personStateOf } from '../kip/PersonKip';
import { Text } from '../ui/text';

// Home F's scene (spec 2026-10-13 Home F §2–§4): the board drawn at 3 points a cell, cropped on narrow phones and
// widened with flat bands on wide ones. Back to front: the backdrop, the grid's four layers, the KIPs, the rain,
// then the tags. The art is hidden from screen readers; the tags carry the meaning. It keeps its colours in both
// themes, so the band colours come from the dark palette.

export type SceneTarget = 'sleep' | 'tomorrow' | 'recovery' | 'recaps' | 'buddies';

export interface SceneReadings {
  sleep: { score: number | null; duration: string | null };
  tomorrow: { low: number; high: number } | null;
  recovery: { score: number; weather: WeatherKey; band: ScoreBand } | null;
  recapsNew: number;
}

export interface HomeSceneProps {
  scene: SceneState;
  /** The screen width in points. */
  width: number;
  /** Extra sky above the grid (sceneExtra). */
  extra: number;
  myColour: KipColour;
  /** null while loading, after a failed read and on an older server: only you. */
  buddies: BuddyScene | null;
  readings: SceneReadings;
  onOpen: (target: SceneTarget) => void;
  onOpenBuddy: (buddyId: string) => void;
}

const C = HOME_COPY;
const PALETTE = COLORS.dark;
const INK = '#F5F5F4';
const NAME_INK = 'rgba(245,245,244,0.9)';
const KEY = { sleep: '#C4B5FD', tomorrow: '#C7D2FE', recaps: '#FB7185', all: '#C7D2FE' } as const;
const EDGE = 4;
const HIDE = { accessible: false, accessibilityElementsHidden: true, importantForAccessibility: 'no-hide-descendants' } as const;

function Paths({ paths }: { paths: { fill: string; d: string }[] }) {
  return (
    <>
      {paths.map((p, i) => (
        <Path key={i} d={p.d} fill={p.fill} />
      ))}
    </>
  );
}

function HotTag({ testID, left, top, screenWidth, keyText, keyColour, value, label, onPress }: {
  testID: string; left: number; top: number; screenWidth: number; keyText: string; keyColour: string;
  value: string | null; label: string; onPress: () => void;
}) {
  const [width, setWidth] = useState(0);
  return (
    <Pressable
      testID={testID}
      accessibilityRole="button"
      accessibilityLabel={label}
      onPress={onPress}
      hitSlop={8}
      onLayout={(e) => setWidth(e.nativeEvent.layout.width)}
      className="flex-row items-center rounded-lg border active:opacity-80"
      style={{
        position: 'absolute', left: clampTagLeft(left, width, screenWidth), top, height: 26, gap: 5, paddingHorizontal: 7,
        backgroundColor: 'rgba(10,11,14,0.82)', borderColor: 'rgba(255,255,255,0.18)',
      }}
    >
      <View style={{ width: 4, height: 4, backgroundColor: keyColour }} />
      <Text className="font-pixel text-label" style={{ color: keyColour }}>{keyText}</Text>
      {value !== null ? <Text className="text-caption font-semibold tabular-nums" style={{ color: INK }}>{value}</Text> : null}
    </Pressable>
  );
}

export function HomeScene({ scene, width, extra, myColour, buddies, readings, onOpen, onOpenBuddy }: HomeSceneProps) {
  const look = STATES[scene.key];
  const offsetX = sceneOffsetX(width);
  const backdrop = useMemo(() => pxPaths(sceneBackdrop(scene.key, width, extra), 1), [scene.key, width, extra]);
  // One path per colour per layer: grouping across layers would paint a later layer's colour under an earlier one.
  const grid = useMemo(() => [laySky(look), layWeather(look), layGround(look), layObjects(look)].flatMap((layer) => pxPaths(layer, U)), [look]);
  const rain = useMemo(() => pxPaths(layRain(look), U), [look]);

  const night = scene.key === 'night';
  const me = kipBox(SCENE_SPOTS.me.cx, SCENE_SPOTS.me.scale, offsetX, extra);
  const shown = (buddies?.buddies ?? []).slice(0, SCENE_SPOTS.buddies.length);
  const tag = (spot: { left: number; top: number }) => at(spot, offsetX, extra);
  const { sleep, tomorrow, recovery, recapsNew } = readings;
  const requests = buddies?.incomingRequests ?? 0;
  const total = buddies?.total ?? 0;
  const allText = requests > 0 ? C.buddies.requests(requests) : total > 0 ? C.buddies.all(total) : null;

  return (
    <View testID="home-scene" style={{ width, height: SCENE_H + extra }}>
      <View testID="home-scene-art" {...HIDE} pointerEvents="none" style={{ position: 'absolute', left: 0, top: 0, width, height: SCENE_H + extra }}>
        <Svg width={width} height={SCENE_H + extra} style={{ position: 'absolute', left: 0, top: 0 }}>
          <Paths paths={backdrop} />
        </Svg>
        <Svg width={SCENE_W} height={SCENE_H} style={{ position: 'absolute', left: offsetX, top: extra }}>
          <Paths paths={grid} />
        </Svg>
        <View testID="home-scene-me-spot" style={{ position: 'absolute', left: me.left, top: me.top }}>
          <Kip testID="home-scene-me" colour={myColour} pose={scene.pose} mood={scene.mood} scale={SCENE_SPOTS.me.scale} />
        </View>
        {shown.map((b, i) => {
          const spot = SCENE_SPOTS.buddies[i]!;
          const box = kipBox(spot.cx, spot.scale, offsetX, extra);
          const { pose, mood } = PERSON_POSE[personStateOf(b.mood, night)];
          return (
            <View key={b.id} style={{ position: 'absolute', left: box.left, top: box.top }}>
              <Kip testID={`home-scene-buddy-${b.id}`} colour={kipColourOf(b.kipColour)} pose={pose} mood={mood} scale={spot.scale} />
            </View>
          );
        })}
      </View>
      {rain.length > 0 ? (
        <View testID="home-scene-rain" {...HIDE} pointerEvents="none" style={{ position: 'absolute', left: offsetX, top: extra, width: SCENE_W, height: SCENE_H }}>
          <Svg width={SCENE_W} height={SCENE_H}>
            <Paths paths={rain} />
          </Svg>
        </View>
      ) : null}

      <HotTag
        testID="home-tag-sleep"
        {...tag(SCENE_SPOTS.tags.sleep)}
        screenWidth={width}
        keyText={C.tags.sleep}
        keyColour={KEY.sleep}
        value={sleep.score === null ? C.none : String(sleep.score)}
        label={C.tags.sleepLabel(sleep.score, sleep.duration)}
        onPress={() => onOpen('sleep')}
      />
      <HotTag
        testID="home-tag-tomorrow"
        {...tag(SCENE_SPOTS.tags.tomorrow)}
        screenWidth={width}
        keyText={C.tags.tomorrow}
        keyColour={KEY.tomorrow}
        value={tomorrow ? C.tags.range(tomorrow.low, tomorrow.high) : C.none}
        label={C.tags.tomorrowLabel(tomorrow)}
        onPress={() => onOpen('tomorrow')}
      />
      <HotTag
        testID="home-tag-recovery"
        {...tag(SCENE_SPOTS.tags.recovery)}
        screenWidth={width}
        keyText={C.tags.recovery}
        keyColour={recovery ? PALETTE[recovery.band] : PALETTE.muted}
        value={recovery ? String(recovery.score) : C.none}
        label={C.tags.recoveryLabel(recovery)}
        onPress={() => onOpen('recovery')}
      />
      <HotTag
        testID="home-tag-recaps"
        {...tag(SCENE_SPOTS.tags.recaps)}
        screenWidth={width}
        keyText={C.tags.recaps}
        keyColour={KEY.recaps}
        value={recapsNew > 0 ? String(recapsNew) : null}
        label={C.tags.recapsLabel(recapsNew)}
        onPress={() => onOpen('recaps')}
      />

      {shown.map((b, i) => (
        <Pressable
          key={b.id}
          testID={`home-buddy-${b.id}`}
          accessibilityRole="button"
          accessibilityLabel={C.buddies.label(b.displayName, b.moodLine)}
          onPress={() => onOpenBuddy(b.id)}
          hitSlop={8}
          className="items-center active:opacity-70"
          style={{ position: 'absolute', left: offsetX + SCENE_SPOTS.buddies[i]!.cx - SCENE_SPOTS.nameWidth / 2, top: extra + SCENE_SPOTS.nameTop, width: SCENE_SPOTS.nameWidth }}
        >
          <Text className="font-pixel text-label" numberOfLines={1} style={{ color: NAME_INK }}>{sceneName(b.displayName)}</Text>
        </Pressable>
      ))}
      {allText ? (
        <Pressable
          testID="home-scene-all"
          accessibilityRole="button"
          accessibilityLabel={requests > 0 ? C.buddies.requestsLabel(requests) : C.buddies.allLabel(total)}
          onPress={() => onOpen('buddies')}
          hitSlop={8}
          className="active:opacity-70"
```

```tsx
// A real comparison against this person's own recent readings -- never a
// fabricated score. Picks whichever metric deviates most from its own
// trailing average (excluding today's own reading from that average).
function computeHeadlineInsight(records: MetricRecord[]): string | null {
  let best: { deviation: number; message: string } | null = null;

  for (const type of METRIC_ORDER) {
    const stats = computeStats(seriesFor(records, type));
    if (!stats || stats.direction === 'steady') continue;
    if (!best || stats.trendPercent > best.deviation) {
      best = { deviation: stats.trendPercent, message: buildHeadline(type, stats) };
    }
  }

  return best?.message ?? null;
}

  const navRef = useRef(navigation);
  navRef.current = navigation;

  useEffect(() => {
    apiFetch<MetricRecord[]>('/me/biometrics')
      .then((r) => { setRecords(r); setError(null); })
      .catch(() => setError('Something went wrong loading your data.'));
  }, [dataVersion]);

  useEffect(() => {
    // A disconnected Google Health is why the data stops updating, so say so
    // rather than leaving the user staring at silently stale numbers.
    apiFetch<{ status: ConnectionStatus }>('/me/connection')
      .then((res) => setConnectionStatus(res?.status ?? null))
      .catch(() => setConnectionStatus(null));
  }, [dataVersion]);

  useEffect(() => {
    // Independent of the metric cards: a scores failure must not take the rest
    // of the dashboard down with it.
    let cancelled = false;
    fetchScoresWithBands(7)
      .then((value) => { if (!cancelled) setScores({ status: 'ready', value }); })
      .catch(() => { if (!cancelled) setScores({ status: 'failed' }); });
    return () => { cancelled = true; };
  }, [dataVersion]);

  useEffect(() => {
    // Last night is dated by the morning you woke up: today. A failed read means "not short".
    let cancelled = false;
    fetchSleep(today, today)
      .then((res) => { if (!cancelled) setNight({ status: 'ready', value: res.nights.find((n) => n.date === today) ?? null }); })
      .catch(() => { if (!cancelled) setNight({ status: 'failed' }); });
    return () => { cancelled = true; };
  }, [dataVersion, today]);

  useEffect(() => {
    let cancelled = false;
    fetchSleepGoal()
      .then((goal) => { if (!cancelled) setBedtime(goal?.bedtimeGoal ?? null); })
      .catch(() => { if (!cancelled) setBedtime(null); });
    return () => { cancelled = true; };
  }, [dataVersion]);

  // The state follows the clock: again on focus, on return to the foreground, and at the next 05:00 or 21:00.
  useEffect(() => {
    const nav = navRef.current;
    const offFocus = nav.addListener?.('focus', () => {
      setHomeFocused(true);
      setNow(new Date());
    });
    const offBlur = nav.addListener?.('blur', () => setHomeFocused(false));
    const appState = AppState.addEventListener('change', (state) => {
      if (state === 'active') setNow(new Date());
    });
    return () => {
      offFocus?.();
      offBlur?.();
      appState.remove();
    };
  }, []);

  useEffect(() => {
    if (!homeFocused) return;
    const id = setTimeout(() => setNow(new Date()), nextSceneBoundary(now).getTime() - now.getTime());
    return () => clearTimeout(id);
  }, [homeFocused, now]);

  const seriesByMetric = useMemo(() => {
    const all = records ?? [];
    return Object.fromEntries(METRIC_ORDER.map((type) => [type, seriesFor(all, type)])) as Record<MetricType, MetricRecord[]>;
  }, [records]);
  const insight = useMemo(() => computeHeadlineInsight(records ?? []), [records]);

  function openDetail(type: MetricType) {
    // Sleep has its own page; the tile's series is the day total that page shows as "with naps".
    if (type === 'SLEEP') openSleep(navigation);
    else navigation.navigate('MetricDetail', { metricType: type, records: seriesByMetric[type] });
  }

  // An unwatched weekly recap rings the avatar in its coach's colour; a tap plays its story
  // instead of opening Profile.
  const ring = useStoryRing(scheme === 'dark' ? 'dark' : 'light', navigation);
  function openProfile() {
    if (ring) navigation.navigate(ring.destination.name, ring.destination.params);
    else navigation.navigate('Tabs', { screen: 'Profile' });
  }

  function open(target: SceneTarget) {
    if (target === 'recovery') navigation.navigate('Recovery', { date: today });
    else if (target === 'sleep') openSleep(navigation);
    else if (target === 'tomorrow') navigation.navigate('Forecast');
    else if (target === 'recaps') navigation.navigate('Recaps');
    else navigation.navigate('Tabs', { screen: 'Social' });
  }

  // The fallback states can't reach anything else on Home, so they keep
  // sign-out right there; the full Home moves it to Profile.
  function fallback({ title, body, action }: { title: string; body: string; action?: React.ReactNode }) {
    return (
      <SafeAreaView className="flex-1 bg-background">
        <View className="flex-row items-center justify-end gap-3 px-5 pt-2">
          <ThemeToggle color={colors.muted} />
          <ProfileButton ring={ring} surface={colors.background} colour={myColour} onPress={openProfile} />
        </View>
        <View className="flex-1 items-center justify-center gap-4 px-8">
          <Character testID="dashboard-fallback-character" mood="idle" size={56} glow paused={!focused} />
          <PageTitle className="text-center">{title}</PageTitle>
          <Text className="text-center text-body text-muted-foreground">{body}</Text>
          {action}
          <Button testID="sign-out-button" variant="ghost" size="sm" onPress={() => signOut()}>
            Sign Out
          </Button>
        </View>
      </SafeAreaView>
    );
  }

  if (connectionStatus === 'DISCONNECTED') {
    return fallback({
      title: 'Reconnect your Google Health',
      body: 'Your Google Health is disconnected, so your data has stopped updating.',
      action: (
        <Button testID="reconnect-health-button" onPress={() => navigation.navigate('ConnectHealth')}>
          Reconnect Google Health
        </Button>
      ),
    });
  }

  if (error !== null) {
    return fallback({ title: 'Couldn’t load Today', body: error });
  }

  if (records === null) {
    return (
      <View testID="home-loading" className="flex-1 bg-background">
        <Skeleton testID="home-loading-scene" className="h-[300px] w-full rounded-none" />
        <View style={{ ...PAGE, paddingTop: 14 }}>
          <View className="flex-row items-center justify-between">
            <Skeleton className="h-[14px] w-[56px]" />
            <Skeleton className="h-[14px] w-[140px]" />
          </View>
          <View className="flex-row gap-[8px]">
            {[0, 1, 2].map((i) => (
              <Skeleton key={i} testID="home-loading-tile" className="h-[96px] flex-1 rounded-tile" />
            ))}
          </View>
        </View>
      </View>
    );
  }

  if (records.length === 0) {
    // Never connected: this is where someone lands on their first sign-in, so
    // it has to offer the connect step rather than describe a sync that cannot
    // happen yet. Connecting is no longer a gate in front of the app, so the
    // dashboard is the thing that asks for it.
    const neverConnected = connectionStatus === 'NOT_CONNECTED';
    return fallback({
      title: neverConnected ? 'Connect Google Health' : 'No data yet',
      body: neverConnected
        ? 'Your scores and trends appear here once Google Health is connected.'
        : 'Check back after your Google Health syncs.',
      action: neverConnected ? (
        <Button testID="connect-health-button" onPress={() => navigation.navigate('ConnectHealth')}>
          Connect Google Health
        </Button>
      ) : null,
    });
  }

  const allScores = scores.status === 'ready' ? scores.value.scores : null;
  // Undefined until loaded (and on an older server): scoreBand uses its defaults.
  const bands = scores.status === 'ready' ? scores.value.bands : undefined;
  const recoveryScore = todayScore(allScores, 'RECOVERY', today);
  const sleepScore = todayScore(allScores, 'SLEEP', today);
  const lastNight = night.status === 'ready' ? night.value : null;
  const weather = todayWeather(recoveryScore, bands);
  const scene = sceneState({ now, recovery: weather, night: lastNight });
  const asRead = (value: DailyScoreDTO | null): Read<DailyScoreDTO | null> => (scores.status === 'ready' ? { status: 'ready', value } : scores);
  const readings: SceneReadings = {
    sleep: {
      score: sleepScore && sleepScore.score !== null ? Math.round(sleepScore.score) : null,
      duration: lastNight ? formatMinutes(lastNight.mainMinutesAsleep ?? lastNight.minutesAsleep) : null,
    },
    tomorrow: forecastRange(forecastState),
    recovery: recoveryScore && recoveryScore.score !== null
      ? { score: Math.round(recoveryScore.score), weather, band: scoreBand(recoveryScore.score, bands) }
      : null,
    recapsNew: shelf.unwatchedCount,
  };
  const metricsWithData = METRIC_ORDER.filter((type) => seriesByMetric[type].length > 0);

  return (
    <View className="flex-1 bg-background">
      {homeFocused ? <StatusBar style="light" /> : null}
      <ScrollView contentContainerStyle={{ paddingBottom: clearance }}>
        <View>
          <HomeScene
            scene={scene}
            width={width}
            extra={sceneExtra(headerBottom)}
            myColour={myColour}
            buddies={buddyScene}
            readings={readings}
            onOpen={open}
            onOpenBuddy={(buddyId) => navigation.navigate('BuddyWeek', { buddyId })}
          />
          <HomeHeader
            top={(insets?.top ?? 0) + 8}
            now={now}
            greeting={greetingFor(now)}
            scene={scene}
            myColour={myColour}
            ring={ring}
            onProfile={openProfile}
            onBottom={setHeaderBottom}
          />
        </View>

        <View style={{ ...PAGE, paddingTop: 14 }}>
          <TodayHeader scene={scene.key} bedtime={bedtime} />
          <TodayTiles
            recovery={asRead(recoveryScore)}
            bands={bands}
            sleepScore={asRead(sleepScore)}
            night={night}
            tomorrow={forecastState}
            bedtime={bedtime}
            onOpen={open}
          />
          <AskCoachButton route={coachRoute} onPress={() => coachRoute && navigateToCoachEntry(navigation, coachRoute)} />

          <HabitLogCard />

          {/* Recaps (decision 5): with the weekly digest below, for every user, coach on or off. */}
          <RecapShelf navigation={navigation} shelf={shelf} />

          {/* The digest is the newest week's recap: it plays that week's story, whose last frame
              offers the full recap. */}
          {coachRoute === 'Coach' ? <CoachDigestCard onOpenRecap={(id) => navigation.navigate('RecapStory', { id })} /> : null}

          {metricsWithData.length > 0 ? (
            <View className="gap-3">
              <SectionLabel>Your metrics</SectionLabel>
              <View className="flex-row flex-wrap gap-3">
                {metricsWithData.map((type, index) => (
                  <Reveal key={type} index={index} className="w-[47%] grow">
                    <MetricTile type={type} series={seriesByMetric[type]} onPress={() => openDetail(type)} />
                  </Reveal>
                ))}
              </View>
            </View>
          ) : null}

          {insight ? (
            <Card className="gap-1.5">
              <SectionLabel>Worth knowing</SectionLabel>
              <Text className="text-body">{insight}</Text>
            </Card>
          ) : null}
          {/* Per-metric trends and the Patterns entry live on the Trends screen (Activity's "All trends"). */}
        </View>
      </ScrollView>
    </View>
  );
}
```
